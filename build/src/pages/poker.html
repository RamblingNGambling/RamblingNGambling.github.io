How to read it

Set the buy-in, then add everyone at the table. Each player starts on one buy-in. Press + for each rebuy. For an odd amount, such as a half buy-in, type the total into the In column.

At the end, type what each player cashed out. Type 0 for a player who lost it all.

When every cash-out is in and they add up to the buy-ins, the payments show here. If they do not add up, the page says by how much. Recount, or split the difference.

Your game stays on your device

The table is kept in this browser only, so a reload in the middle of a game loses nothing. New game clears it. Copy link puts the whole table into the address, so anyone you send it to opens the same numbers.
