04How it works

One bet, repeated

What it is

One bet, repeated: Shai Gilgeous-Alexander to score 20 or more points. Every game he plays, the whole return from the last one goes on the next. There is no top-up and no side bet.

Why it is a multiple

Like the rest of this site, it is units only. What is shown is how many times it has been multiplied, so 2.00x is a stake that has doubled. That reads the same whatever the stake was.

What ends it

One miss. The whole roll goes with it and the run is over; the game is logged as a loss at the multiple it was carrying. A game he sits out is void: the stake comes back and rolls to the next one.

Proof of placement

Each game has a screenshot of the bet slip, taken when the bet was placed. Ticket numbers are blurred before a screenshot is saved.

Where the prices come from

Each game is logged at the price taken, before it starts. A win multiplies the roll by that price, so at −900 a win is worth 1.11x and the run only gets big if it lasts. The data is public: sga.json.
